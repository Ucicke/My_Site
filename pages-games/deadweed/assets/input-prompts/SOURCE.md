# Kenney Input Prompts 1.5

Author: Kenney.
Source: https://kenney-assets.itch.io/input-prompts
License: CC0 1.0 Universal; original License.txt retained as LICENSE.txt.
Downloaded: 25 October 2026 (Moscow).

Included: unmodified Default PNGs for A–Z, 0–9, F1–F12 and supported special keyboard keys; Xbox Series and PlayStation prompts for current game actions. Files were flattened into this directory without changing names.

Combat pickup/merge/inspect hints and menu prompts use these icons. The rebinding screen also shows the actual keyboard key. Lookup follows Input.bindingCode; unknown keys retain text labels. Xbox is the standard-layout fallback; PlayStation is selected by recognized controller IDs. This changes presentation only: button assignments and pickup rules are unchanged.
