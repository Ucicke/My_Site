# Generated whole-plant sprites and ground

Created with the built-in OpenAI imagegen tool for DEADWEED, using `enemies.png` as a material/style reference for each creature. The runtime PNGs are resized to 512 pixels wide with Lanczos filtering, preserving transparency; the ground is resized to 768 × 768. Originals remain in the image generator's output directory.

Match reference's detailed organic weapon-like materials but make ONE complete cohesive creature, not disassembled parts.”
