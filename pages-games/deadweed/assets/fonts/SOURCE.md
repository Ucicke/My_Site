# Not Jam Mono Clean 13 / 16

Author: Not Jam.
Source: https://not-jam.itch.io/not-jam-mono-clean-13
License: CC0 1.0; original text is in NOT-JAM-LICENSE.txt.
Downloaded: 25 October 2026 (Moscow).

The download includes 13px and 16px variants. Both unmodified TTFs are included. The 13px variant supplies only the Latin DEADWEED logo. The 16px variant supplies menu labels and numeric readouts; its cmap contains all 66 Russian letters (including Ё/ё). The 13px variant lacks Cyrillic and is never assigned to Russian copy.

Body descriptions keep the existing system monospace font. The CSS font-display: swap policy and Canvas fallback keep the game usable if the font fails to load.
