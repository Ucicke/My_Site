# ucicke.ru — сайт Ивана Брежнева

Самостоятельный проект портфолио Ucicke. Для работы над сайтом не нужны
LifeSim, Python, MongoDB, Svelte или установка npm-пакетов.
Требуется только Node.js 20+; для публикации — PowerShell, OpenSSH и tar.

## Работа над сайтом

Откройте **эту папку** отдельным проектом в редакторе / Codex.

- `index.html` — тексты, карточки игр, профили, SEO и структура страницы.
- `site-assets/styles.css` — вся вёрстка и оформление.
- `site-assets/favicon.svg` — собственная иконка сайта.
- `scripts/` — локальный сервер и сборка без внешних зависимостей.
- `deploy/` — собственная публикация сайта.

```powershell
npm run dev
```

Предпросмотр: http://127.0.0.1:4174/. Изменили HTML/CSS — обновите страницу.
Ссылки `/lifesim/` и `/deadweed/` работают на опубликованном домене;
локальный сервер не запускает игры.

```powershell
npm test
npm run build
```

Сборка находится в `dist/` и содержит только `index.html` и `site-assets/`.
Её можно разместить на любом статическом хостинге. Сайт работает без JavaScript.

## Публикация

Локальный `deploy/deploy.env` уже заполнен при переносе и исключён из Git.
Для нового компьютера используйте `deploy/deploy.env.example`, собственный SSH-ключ
и предварительно проверьте обычное SSH-подключение к серверу.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File deploy/deploy_site.ps1
```

Скрипт сам собирает сайт и публикует его в отдельный релиз `/opt/ucicke_site/releases/`.
Он меняет только `public_html/index.html` и `public_html/site-assets`, сохраняя
предыдущие версии в `previous-public-files` внутри релиза. Бэкенды и игровые
каталоги не затрагиваются. Общий файловый lock исключает гонку с деплоем игры.

Для отката возьмите `previous-public-files/index.html` и `site-assets` нужного
релиза. Старые релизы не удаляются автоматически. Не выкладывайте секреты из
`deploy.env` в Git и не заменяйте весь web docroot содержимым `dist/`.

## Отдельный репозиторий

У сайта своя история Git. Репозиторий LifeSim не используется ни при разработке,
ни при сборке, ни при публикации портфолио.
